## 4. Cross-cutting QLS patterns (check on every case)

### 4.1 Oracle, not SQL Server

QLS is the **only** upstream product in this KB running on **Oracle**. Core schema is **`lis`**; every diagnostic query in the skills is Oracle syntax (`ORA-#####`, sequences, packages, `MERGE`, `TO_NUMBER(... DEFAULT ... ON CONVERSION ERROR)`).
Companion schemas: `QLS_QFCONL` + `ESUITE_QFC` (QFC config, queue, object repository), `QGIS` / `QGIS_ARCH` (feature classes, Polygen config, SDE), `QLAI` / `QLAE` (QLA web suite + interface packages), `ESUITE_QAPA` (QLA code-table sync).
Practical consequences: **sequence drift** (`STIP_SEQ`, `AFIS_GL_XREF_SEQ`, `arrg_key`) is a recurring G4 bad-data family; **triggers** (`TR_LD_METES_BOUNDS_LGL_DTL`, `LIS.TAR_ALL_AGREEMENTS`) and **PL/SQL packages** (`ACRE_CALC`, `PCK_UPDT_MAP_STATUS_CORE`, `QLA_INFC_QLS_CORE`) are first-class root-cause locations; **SDE compress** and Oracle version differences (ORA-43907 on older Oracle) affect performance and backports.

### 4.3 Client metadata-layer overrides

Configuration and screen metadata resolve through layers (`APP_LAYER_CD`: CORE → ENV → client, plus `METADATA_PROFILE` on the GIS side). Recurring failure modes:

- **Missing client layer** → Copy Agreement "copy notes failed: NullReferenceException" (missing `QCLNT` layer); Polygen config `ORA-00001` on `PK_QARCH_GIS_POLYGEN` when `METADATA_PROFILE` is unset.
- **Stale layer after an upgrade / V17 move** → "Type of Change" dropdown blank (stale `QCEN` layer), security roles/sysgen missing (`ORA-02291`), config keys reset by deployment.
- **Client override repos** `<CLIENT3>.QLS.Metadata` hold the shipped client config (e.g. `QARCH_CNFG_CTRL.json` under `STANDARD 16.0/`) — always check the client repo before declaring a config value a product default. See [code_logic/REPO_REFERENCE_QLS.md](code_logic/REPO_REFERENCE_QLS.md).
- **Client-custom code exists** — `ADAMPPFDEO` Positive Pay proc, `QLA_INFC_QLS_CRI`, client triggers on `LIS.DEP_REL_WELL`, `GET_AGREEMENT_ATTRIBUTES` registered SQL. Per `code-investigator`: check the client override before the core repo.

### 4.4 Recurring themes visible across the 13 triage tables

1. **G3 dominates.** Payments date-roll/status-flip, Related-Wells grid, Copy Agreement, Mass Change notes, Chain-of-Title notes, formations-on-save — all hotfixed across 2022.04→2026.04. **Check the build before investigating code**, every time.
2. **"Process missing from the Batch Processes screen" is one root cause, three skills.** `QARCH_CTRL_PROCESS_TYPE` / `QARCH_CTRL_PROCESS` metadata rows: Batch §3.1, Integration §3 A1, Security §3.3 (BTYP security). Clean 2025.04+/2026.04 DBs ship **without** the AFISCRTAE row (ADO 1814705).
3. **"Worked before the refresh/patch" → connection & metadata drift.** `QARCH_CTRL_CONNECT_INFO` dataHelper rows (`QLS`, `ESB`, `QCADataHelper`, `UPSDataHelper`), scheduler params, export/FTP host details, post-refresh scripts. Integration §3 A2 and §6 D are the two highest-volume instances.
4. **Registered SQL and grid metadata are config, not code.** `QARCH_SQL` entries (`SELECT_PROV_RESPONSE_VALUE_LIST_BY_CATG[_WEB]`, `SELECT_RELATED_WELL_ENHC`, `SELECT_PICK_REL_AGREEMENT`, `RESET_ABORTED_CHECK_RUN`, `GET_AGREEMENT_ATTRIBUTES`) and grid column metadata (`QARCH_CNFG_GRIDCTRL_COL_NET`, `QARCH_CDTBL_DEFINE_COL`) explain a large share of "dropdown empty / wrong order / column missing" cases → **G2**, not G5.
5. **Conversion debt is a permanent family.** V7→V17 and acquisition conversions leave missing notes, missing cross references, "STD" financial-org levels, dead OpenText links (`CONVERT_IND`), unmapped provisions. Route to the owning skill's conversion cluster; the fix is usually a script (`Quorum.QLS.Conversion`), not a defect.
6. **Sequence-behind-MAX(key) is the signature G4 fix.** `STIP_SEQ`, `AFIS_GL_XREF_SEQ`, `arrg_key`, `SCTRL_CONTACT`. Symptom is always "save silently fails" or "PK violation on insert".
7. **Aborted runs leave half-written state.** Aborted check runs (`RESET_ABORTED_CHECK_RUN`; ADO 1772699 also marks the *next* event processed), aborted ECALWF runs (orphaned desk assignments), aborted mass deletes (child data gone, agreement left). Ask "was a run cancelled or aborted?" early.
8. **Security symptoms masquerade as functional ones.** A missing node, batch process, report, widget, or Prospect tab is usually a security object (`QARCH_SEC_OBJECT`, `QVIEWRELATEDASSET`, `QLSWIDGETACCESS`, BTYP rows) — and object-name **casing** matters (Polygen/Grid Source security objects must be camel-case).
9. **Root-cause triage first.** Software Defect (1,063) / Application Configuration (1,507) → investigate. Training (1,205) / Customer Error (1,037) / Business Change (1,252) → expected-behavior answer. Customer Cancelled / User Administration / Cloud Outage → service request. 3,499 cases (24%) have a null root cause — mostly older or cancelled.
10. **QLS case detail lives in CaseFeed.** `Type='TextPost'` — CaseComment and EmailMessage are empty for this product. Intake must query CaseFeed or it will report "no fix detail".
