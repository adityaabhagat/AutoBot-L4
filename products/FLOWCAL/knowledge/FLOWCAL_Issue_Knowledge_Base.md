## 3. Cross-cutting FLOWCAL-family patterns (check on every case)

1. **Service-restart family** — a huge share of Services/Imports/Reports tickets resolve by restarting the owning `FcSrv*` service (or its whole set when the shared `FCSRV` Windows/Oracle account is locked or password-expired — that stops ALL services at once). Always ask: which exe, is `FCSRV`/`svcfcinstant` locked, was there a memory leak (pre-10.5), is Oracle at max processes? Restart drill lives in Imports §4.1 / Reports §3.1 / Services §3.1.
2. **10.8 StringCopy defect family** — "Destination buffer too small! Will truncate" / string buffer overflow (`FCSystem::CheckTruncation`, `SetFlowCalString.h`) hits imports, rollups, and editors on 10.8.x. Interim: `FcDebugOptions.cfg` `[ALL_USERS] disable_string_copy_checks=Y`; fixed 10.8.0.7/10.8.0.8/10.9.0.1 (INFERRED). Check version before deep-diving.
3. **CrypKey licensing is the biggest raw-volume family (~9.1k cases) but mostly ops, not defects** — site-key issuance/transfer recipes, `Ckldrv.sys`/`crp32002.ngn` engine failures on VMs/RDS, policy-file date sync. Fast recipe in Licensing §3; "All licenses in use" can masquerade as an access issue (Security §8).
4. **`R####` port convention in ADO** — measurement bugs are cloned per release branch with title suffixes `(DEV)` / `(R1090 PORT)` etc. (R1090 = 10.90). When checking "is it fixed", find the port sibling for the client's branch, not just the DEV item.
5. **EEFFACE is a symptom, not a root cause** — `External exception EEFFACE` appears in editors (MeterEdit §3.2), reports (Reports §8.2), Validation Set Points (Exceptions §4), Time Frame Edits (`FCTIMEFRAMEEDITS.DLL`, UI §3.1/§3.8). Route by the screen it fires on; null `FC_LOCATION.LOCATION_NUMBER` rows are a known data-shaped cause.
6. **Duration/edit-reason data corruption recurs product-wide** — meter-characteristics duration gaps, `fc_gq_source` duration/end-date corruption, `FC_EDIT_REASON` explosion (65000+ rows, 32-bit epoch overflow at 2147483647). The **Duration Fix utility** and periodic edit-reason cleanup are the standard remedies (Imports §9.3, Services §5.1, MeterEdit §4.1, Calculations §3.5).
7. **Desktop profile corruption (TESTit/PROVEit)** — `CAppDATUtils`/`CMiscUtils` errors ("same key has already been added", "not a valid Base-64 string", "Could not find file …Default.xml", "root element missing") = corrupt `fieldapplications.dat` / `%LOCALAPPDATA%` layouts. Delete/rebuild local state (FieldOps §3.1, UI §3.7).
8. **QCloud-hosted is the dominant deployment** — login/env/SFTP symptoms usually route to FLOWCloud_Hosting or Security_Access first; hosted-but-functional failures route onward (FLOWCloud §3.6). PRD data-state claims from DEV-tier metadata connections stay INFERRED.
9. **Root-cause triage first** — `Software Defect`/`Application Configuration` → real investigation; `Training`/`Customer Error` → expected-behavior answer; `Licenses` → site-key ops recipe; `Database Refresh Request`/`User Administration Request` → ops runbook.
10. **Process caveats (mining-confirmed):** `CaseComment` is EMPTY for FLOWCAL — fix detail lives in `Description` + `Resolution__c` + `EmailMessage`. The Salesforce MCP connector intermittently cross-delivered another session's result set under parallel calls — run SOQL sequentially and validate every result set against its WHERE clause. SOQL `LIKE '%AGA%'` also matches "again"; unbounded `ORDER BY ClosedDate` times out — use `CreatedDate` windows.
