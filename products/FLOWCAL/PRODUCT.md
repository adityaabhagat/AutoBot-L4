## Mining process caveats (confirmed 2026-09-02/03)

- `CaseComment` is EMPTY for FLOWCAL — fix detail lives in `Description` + `Resolution__c` + `EmailMessage`.
- The shared Salesforce MCP connector intermittently returned crossed/cross-session responses under parallel or timed-out calls — run SOQL sequentially, validate every result set against its WHERE clause, and retry solo on mismatch. Never batch SOQL calls in parallel.
- SOQL `LIKE '%AGA%'` also matches "again"; unbounded `ORDER BY ClosedDate` queries time out — use `CreatedDate` windows.
