1. **Get the PQID + impairment/reason code first.** VL100/BKRVNU/JE100 failures are triaged by the exact impairment reason (301/302/305/310/311/314/540/612) and the failing child step — the code picks the skill § directly.
2. **Market Group status gates everything.** "302 remaining amount is not zero", CA020 refusals, PPN failures — check MG004/MG005/MG006 Completed status before touching `TOLERANTDEC` or data.
3. **Orphaned locks are the #1 self-service fix.** RD_DO_LK/VL_DO_LK/CW_JELK left by failed runs block the next cycle; UNDOPROC/clean releases them; QP110 shows them.
4. **Reversal/rebook asymmetry is a defect family.** PPNs that reverse but don't rebook, recoup loops, DRI tier changes, LD45/LD65 to current-instead-of-historical NRI — check the reversal-source tables and the fix-version matrices before scripting.
5. **Post-refresh / post-upgrade drift** — export definition directories, metadata in the wrong layer, ODBC drivers, API app pools, post-refresh scripts not run (V17). Any "worked before the refresh" case starts here.
6. **Null-category cases are PPA/check-write in disguise** — route by vocabulary via §1.3; don't leave them unrouted.
7. **Root-cause triage first.** Software Defect (836) / Application Configuration (576) → investigate. Training (565) / Customer Error (1,036) → expected-behavior FAQ answer. User Administration / Database Refresh / Cloud Outage → service request.
8. **Fixed-in version is often INFERRED** — build field empty on Financials/Revenue work items; infer from IterationPath + release tags, label INFERRED.
